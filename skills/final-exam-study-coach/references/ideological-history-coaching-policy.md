# 思政历史逻辑填空带教规则

本文件用于中国近现代史纲要、思想政治理论课、政治理论、历史类课程的带练。目标不是把学生训练成机械背诵，而是让答案从背景、矛盾、主体、对象和任务中自然推出。

## 核心原则

思政历史类知识点默认先搭推导坡道，再做填空。不要一上来连续问“是什么”，尤其不要在学生刚接触或刚答错时裸问；也不要先把答案或答案的同义说法讲出来，再让学生机械填同一个词。每轮带练应让学生从背景、矛盾、排除项和任务中自己推出关键词。

逻辑填空不能只服务一级骨架。每完成若干个大框架后，必须把同一逻辑推进到二级采分细节，例如时间、会议、人物、主体、对象、基本纲领、历史地位的展开项、意义中的固定搭配、经验教训中的关键词。主观题关键词优先不等于细节不重要；它只是说表达细枝末节不要过度纠缠，真正影响采分的二级细节必须覆盖和抽查。

推荐顺序：

```text
背景/矛盾 -> 排除错误方向 -> 任务或评价标准 -> 答案应具备的性质 -> 学生推出关键词 -> 只纠核心词
```

硬要求：

- 提问前不要泄露待填的核心词，也不要泄露它的直接同义词。
- 先告诉学生“为什么不是别的答案”，再让学生想“那应该是什么答案”。
- 如果答案是固定政治术语，可以先让学生说出性质或方向，再逐步收束到标准词。
- 学生推不出时，先给词类、时代阶段、主体对象等最小提示，不直接灌完整答案。

## 标准带练格式

```markdown
这题的推导坡道是：
1. 当时卡住的问题是……
2. 已经证明走不通/不够彻底的是……
3. 这道题真正问的不是……，而是……
4. 所以空里应该填一个表示……的核心词。

现在你填：
____ 是/体现/回答/标志/要求 ____。
```

解释控制在 2-5 句，不能变成长篇灌答案。问题仍然保持一问一答，但提问前必须给足能推出答案的逻辑，并且不能提前把答案说穿。

## 什么时候可以直接短问快答

只有以下情况可以直接问：

- 学生已经理解过该知识点，现在是在考前回炉。
- 前一轮刚讲过逻辑，现在只做快速检索。
- 题目本身是客观题易混点，需要训练瞬间识别。

如果学生说“不理解、背不住、为啥是这个、这俩有啥区别”，必须停止短问快答，回到逻辑链。

## 纠错尺度

主观题以核心关键词和逻辑层次为主：

- 核心关键词错、漏、混，必须纠正。
- 时代阶段错、主体对象错、性质任务错，必须纠正。
- 核心词正确但语序、连接词、同义表达不影响采分，不反复纠缠，只补一句更稳写法。
- 客观题、填空题、判断题可以提醒标准表述，但也要说明为什么这个词是陷阱。

## 示例

错误带法：

```text
中国革命的中心问题是什么？
```

更好的带法：

```text
这题不是问革命对象，也不是问革命道路，而是问“谁来领导革命”。近代农民阶级、地主阶级改革派、资产阶级方案都没能完成反帝反封建任务，所以中国革命需要一个更先进、更有组织性的阶级来掌握方向。既然题干问“中心问题”，它实际在追问革命领导权归谁。

现在你填：中国革命的中心问题是____领导权问题。
```

## 常用逻辑桥

- 问“标志”：找历史节点带来的制度性质变化。
- 问“意义”：答它改变了什么、推动了什么、为后来什么奠基。
- 问“原因”：按领导、理论、群众、道路、敌我条件分层。
- 问“道路”：答怎么走、依靠哪里、用什么方式达到目标。
- 问“理论回答了什么”：看它对应的时代问题。
- 问“本质/特征/优势”：找最能决定方向和制度性质的主体。
- 问“细节展开”：先定位一级骨架，再追问时间/会议/主体/对象/性质/内容/意义/固定搭配中缺哪一格。
- 问“客观题陷阱”：优先比较相邻阶段、相似会议、相近理论、易混主体和固定搭配。

## 禁止做法

- 禁止先说“答案是某某，因为……”，再让学生复述。
- 禁止把答案同义改写后藏进解释里，例如要填“无产阶级领导权”，前面却直接说“先进阶级掌握领导权”后只让学生补“无产阶级”以外的机械空。
- 禁止学生一错就直接给标准答案；应先指出他走到了哪条错误分支，再让他沿正确分支补一次。
- 禁止把“逻辑讲解”变成大段背诵材料；推导只服务于推出本题核心词。
