# 当前时间戳与计划刷新规则

本文件用于修复跨天继续、考后切换、晚上/白天计划不变的问题。复习计划必须以当前系统时间为准，而不是以旧文件生成日期或聊天记忆为准。

## 触发场景

以下情况必须先做时间戳预检：

- 用户说“继续复习”“下一门”“今天学什么”“今晚学什么”“明天考试”“考前”“还有多久”。
- 对话跨天、上下文压缩、恢复长期计划。
- 读取任何旧计划、旧 checkpoint、旧考前清单。
- 用户刚考完一门，准备切换下一门。
- 用户指出时间不对、计划没变、现在不是晚上/早上。

## 当前时间来源

优先使用可执行系统时间：

```bash
python scripts/current_time_context.py --json
```

如果需要同时计算考试倒计时：

```bash
python scripts/current_time_context.py --json --exam "课程名|2026-06-29 16:00"
```

如果脚本不可用，使用等价系统命令读取当前日期、时间和时区。不能只看旧计划文件名、旧生成日期、历史聊天或用户相对说法。

## 必须输出或内部使用的字段

- 当前日期：`YYYY-MM-DD`
- 当前时间：`HH:MM`
- 当前时区
- 当前星期
- 最近未来考试
- 距离最近考试的天数/小时数
- 当前学习阶段：普通复习、48 小时内、24 小时内、考前三小时、考后切换、已过期
- 旧计划是否过期

## 旧计划失效条件

满足任一条件就不能照旧执行：

- 旧计划生成日期早于当前日期，且计划里有“今晚/明天/当天”等相对安排。
- 当前时间已超过某门考试结束时间。
- 最近未来考试已经不是旧计划所指课程。
- 剩余时间进入 48 小时、24 小时、3 小时等新阶段。
- 用户实际完成/未完成情况与旧 checkpoint 不一致。
- 新增材料或老师范围变化。

## 重排规则

1. 已过考试：标记为已结束，不再安排常规复习；只在用户要求复盘时处理。
2. 最近未来考试：置顶为当前课程。
3. 多门课：按考试时间排序，再看提分收益；不能补远期课压过最近考试。
4. 少于 48 小时：先保高频覆盖、主观模板、客观易混。
5. 少于 24 小时：未覆盖高频点优先于普通错点回炉。
6. 最后 3 小时：只做清单化回顾、错词修正和状态维护。
7. 晚上恢复：默认低负荷切换或短块学习，不安排高强度长计划，除非用户明确说精力充足。
8. 早晨/考前恢复：默认快速回忆、错点清单、稳定状态。

## 回复模板

```text
时间校准：现在是 YYYY-MM-DD HH:MM（时区），距离最近考试【课程】还有 X 天 Y 小时。
旧计划状态：有效/需要重排，原因是……
当前策略：……
现在只做下一块：……
```

## 禁止事项

- 禁止说“今晚/明天/今天”但没有校准当前时间。
- 禁止历史考完后继续按历史考前计划复习。
- 禁止上午、下午、晚上都执行同一学习块。
- 禁止因旧 checkpoint 写着“今晚”就忽略真实系统时间。
- 禁止只更新文字计划，不改变下一步带练内容。
