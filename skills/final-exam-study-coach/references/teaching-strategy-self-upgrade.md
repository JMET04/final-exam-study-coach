# 讲解策略自我升级

目标：同时改进教师的分析质量和讲解方式。先判断是不是教师漏条件、误选模型、错查参数或割裂主线，再评价学生的理解。教师质量记录与学生掌握记录分开。

## 教师分析缺陷的修复

用户指出漏验、步骤不知用途、参数无来源或知识点割裂时，暂停该段推进，按 [系统化教学流程](systematic-knowledge-and-problem-coaching.md) 重建相关单元与整题路径，不能只给原答案追加一项。

记录实际失误 → 影响范围 → 来源证据 → 改动的决策步骤 → 能改变结论的反例 → 验证结果与仍未验证项。反例要检验方法是否会换分支或拒绝错误结论，不做只检查文案标题存在的测试。修复若只核当前单元，应明示范围，不能宣称所有课程已经重整。

这类记录不调用学生理解评分脚本，不写成学生 confused，不修改掌握度或复测时钟。公式与流程核验通过，只证明本轮核验范围；学生教学效果仍需以后实际反馈。

## 记录什么

每次较完整的讲解、答疑、错题订正或作业批改后，记录一条讲解案例：

- **学生画像**：当前掌握度、常见错因、学习速度、偏好的表达方式、情绪状态。不要写隐私身份信息。
- **知识点场景**：课程、知识点、题型、前置知识、学生原始问题。
- **讲解策略**：类比讲法、图像/动画、公式优先、例题优先、步骤拆解、故事线、反例对比、考试模板等。
- **讲解内容摘要**：本次怎么讲的，给了什么例子或图。
- **理解证据**：学生复述、短测结果、能否做变式题、学生反馈。
- **效果评分**：讲前置信度、讲后置信度、结果是 understood/partial/confused。
- **下次建议**：同类情况优先继续用什么讲法，或避免什么讲法。

## 学生画像边界

- 画像只能描述学习行为和当前状态，例如“公式符号易混”“需要先看图再推公式”“做题慢但能复述”。
- 不要用固定标签给学生下定论，例如“这个学生就是笨/文科脑/理科脑”。
- 如果证据不足，只写“暂不确定”，不要过度归因。
- 学生状态会变化；旧记录只能作为候选，不是永久判断。

## 自我升级循环

1. **讲前选择**：检索同课程、同知识点、同错因、相似学生画像的历史记录。
2. **讲中适配**：先用推荐策略讲一小段，再用复述或短测检查。
3. **讲后记录**：记录讲法、学生反应和理解证据。
4. **下次优化**：如果某策略连续有效，提高优先级；如果学生仍 confused，换另一种讲法。

## 推荐规则

- 精确匹配优先：同课程 + 同知识点 + 相似学生画像。
- 次级匹配：同知识点或同错因。
- 泛化匹配：同学科类型和同学习状态。
- 不要只看学生自称“懂了”；至少结合一个复述、短测或变式题结果。
- 当历史样本少于 2 条时，只能说“暂时建议”，不能说“最适合”。

## 输出模板

讲解前：

- **历史策略检索**：过去同类学生/同类卡点哪种讲法有效。
- **本次讲法选择**：为什么先用这种讲法。

讲解后：

- **理解证据**：学生复述/短测/变式题表现。
- **策略效果**：讲法是否有效，讲前讲后置信度变化。
- **下次讲法建议**：继续使用、降级重讲或换策略。
- **记忆更新**：写入讲解策略记忆库。

## 脚本

使用 `scripts/update_teaching_strategy_memory.py` 记录和推荐策略。

记录样例：

```bash
python scripts/update_teaching_strategy_memory.py record teaching_strategy_memory.json --record-json teaching_case.json
```

推荐样例：

```bash
python scripts/update_teaching_strategy_memory.py recommend teaching_strategy_memory.json --course 土力学 --concept 有效应力 --student-profile "符号易混,需要步骤拆解" --output recommendation.md
```

在 Windows 中文环境下，推荐使用 UTF-8 JSON 输入，避免命令行中文参数乱码：

```bash
python scripts/update_teaching_strategy_memory.py recommend teaching_strategy_memory.json --query-json teaching_query.json --output recommendation.md
```
