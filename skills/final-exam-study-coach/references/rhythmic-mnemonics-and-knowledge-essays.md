# 顺口口诀与知识小论文口播

## 适用入口

- 用户说“编个口诀、顺口一点、压成顺口溜、怎么好背”：使用“顺口口诀”。
- 用户说“写成知识小论文、专业知识口播、像短视频那样讲、抖音小论文”：使用“知识小论文口播”。
- 用户提供视频或音频作为表达参考：先走“声音样本校准”，只抽取声音和表达结构，不分析画面，不复刻原作者的特色长句。

这两种形式是有梗模式的扩展，不改变标准答案、老师符号、题目条件、带练节奏、错题回炉和考试覆盖计划。口诀负责压缩，口播负责把知识放进一条可理解的叙事线；二者都不能代替第一次严谨讲解。

## 一、顺口口诀

### 1. 先确定要记什么

先把材料拆成最小知识骨架，并判断它属于哪一种：

| 骨架类型 | 必须保留 |
|---|---|
| 并列清单 | 每个标准关键词；不要虚构先后关系 |
| 有序步骤 | 原顺序、动作和条件 |
| 因果链 | 原因、方向、结果 |
| 对比边界 | 比较对象、判据和例外 |
| 公式关系 | 老师原符号、条件、方向和时点 |

如果知识骨架本身还不确定，先回材料核对，不要为了押韵补词。

### 2. 把“顺口”做成节奏

优先使用自然汉语的短节拍：

- `二二 / 二二`：短清单，如“先判类型，再找条件”。
- `三三 / 三三`：步骤或对比，如“看时点，认方向；跨几期，换几期”。
- `四四 / 四四`：完整关系，如“对象定任务，条件定方法”。
- `先……再……；有……才……`：有顺序或门槛的过程。
- `不是……而是……`：只用于真正的易混边界。

尾字押韵是加分项，不是硬指标。优先保证节拍整齐、停顿自然、关键词落在重读位置。不要倒装标准术语，不塞“呀、啊、忙、强”等无信息衬字凑韵。

### 3. 生成与筛选

默认只给一个最佳版本；学生明确要挑选时再给 2-3 个候选。候选按以下顺序筛选：

1. **准确**：每个节拍都能唯一映射回一个标准词或关系。
2. **完整**：没有漏掉会影响得分的关键词、条件或顺序。
3. **顺嘴**：连续读两遍不拗口，不需要先解释谐音。
4. **短**：通常 8-32 个汉字；较长清单可拆成上下两句。
5. **可检索**：遮住标准答案后，学生能用口诀还原；遮住口诀后，学生仍能说出标准答案。

先做一次“是否值得改写”判断：如果标准表述本身已经短、整齐、顺口，优先保留原句，只标停顿和重读，不要为了显得有创意而改差。不得只在原词后面添加“摆前头、放中间、来收尾、第一第二第三”等位置标签；这种写法没有提供语义线索，属于排列标签式伪口诀。新增的每一拍要么解释作用，要么提示关系、顺序原因或易混边界，否则删掉。

**短固定表述保真门**：若答案由 2-4 个并列短语构成、每项约 2-6 个字、总长不超过 24 个字，而且读起来已有整齐节拍，口诀正文必须逐字保留这些标准短语。此时只用停顿、重读和一句语义映射帮助记忆，不替换成近义词。比如“安全第一、预防为主、综合治理”本身就是四字三拍，最佳口诀仍是原句，不改成“抓住主线”等非标准说法。

输出顺序：

```text
标准表述：……
顺口记：……
对应关系：短句甲 -> 关键词甲；短句乙 -> 关键词乙。
现在不看口诀，你按原顺序说一遍。
```

教学对话中可省略“对应关系”的显式标题，但首次使用新口诀时必须解释一次映射。

### 4. 口诀禁区

- 不改老师字母、上下标、公式或标准术语。
- 公式和符号按字符级保真：直接复制来源中的公式字符串，不把 `'` 自动改成 `′`，不把 `-` 自动改成 `−`，不改全角/半角、上下标或字母大小写；展示公式后逐字符快速核对一次。
- 不用字母谐音、低俗谐音、攻击性称呼或只有特定圈子懂的热梗。
- 不为押韵调换有严格顺序的步骤。
- 不把并列清单编成虚假的因果链。
- 不把适用条件、否定词、程度词和例外删掉。
- 不生成只能背出声音、无法解释意义的“乱码口诀”。
- 不用“前头/中间/收尾”代替真正的记忆映射；若只有顺序标签而没有知识意义，退回标准原句。

## 二、知识小论文口播

本节只规定通用知识骨架与准确性。用户要“戳心、调侃恋爱、像参考视频、知识小论文”时，必须继续读取 `emotional-knowledge-monologue.md`；不能用本节的普通说明型口播冒充戳心成品。

这里的“小论文”指 20-90 秒、有一个中心观点和完整推进的知识口播，不是学术论文，也不是把术语贴在鸡汤上。

### 1. 使用时机

- 适合：第一次严谨解释之后的第二次编码、章节导入、阶段复盘、专业认同、跨概念串联。
- 不适合：学生尚未获得最低前置知识、最后几小时只抢标准答案、复杂计算正在逐步列式、内容涉及现实高风险操作。
- 学生基础较弱时，先给概念骨架，再用口播降低陌生感；学生基础较强时，可用口播串联多个关系，但仍要控制在一个中心观点。

### 2. 知识骨架

写作前先列出以下内容，缺一项就不开始润色：

```text
中心知识：
必须原样保留的术语/符号：
要讲清的唯一机制或逻辑链：
适用条件或边界：
希望学生听完能回答的问题：
目标时长与语气：
```

一条口播只承载一个主机制，最多带 2-4 个相关知识锚点。公式较长时，口播负责解释关系，完整公式同时作为屏幕文字或紧随口播给出；不能为了好听把公式读错或省掉关键条件。

口播只能展开材料已明确给出的机制。想补充一个常见结论时，先核对其成立条件，并把条件说出来；如果材料没有给条件、又无法核实，就不加。尤其不能由一个静态公式擅自推出排水、固结、强度变化、历史动机或政策效果等额外结论。

### 3. 六段推进

不机械标号，但内容按以下逻辑自然推进：

1. **生活入口**：用一个真实问题、现象或矛盾开门，不用虚假悬念。
2. **认知落差**：指出直觉为什么不够，形成继续听的理由。
3. **专业概念登场**：准确说出术语，不让术语只做装饰。
4. **机制推进**：用“因为 -> 所以”或“条件 -> 变化 -> 结果”讲清核心知识。
5. **回扣现实**：把专业关系放回开头场景，产生理解后的反转或余味。
6. **学习落点**：用一个不泄题的小检索，让学生脱离文案复述概念、因果、边界或列式。

短口播可以合并相邻两段，但不能省掉“专业概念”和“机制推进”。

一问一答检查时，本轮只提出问题，不在同一条消息中紧跟“答案/解析”。等待学生作答后再判断；只有用户明确要求“带答案成稿”或正在生成教师版材料时，才附答案。

带教消息必须在唯一一个检索问题处结束；问题后不得再出现“答：”“答案是”“所以应为”等内容，也不得连续问两个问题。所谓“一问一答”是助手问一次、等待学生答一次，不是助手同时编写问答对。

### 4. 语言节奏

- 以可说、可停、可听懂为标准；句子多数为 8-22 个汉字，长短句交替。
- 每 2-4 句完成一次推进，不连续堆比喻、排比或金句。
- 允许一句轻反差或一句有余味的回扣；不要求句句“炸”。
- 重要术语在首次出现时落在短句末尾或停顿前，便于听觉抓取。
- 口语可以自然，知识必须精确。宁可少一个修辞，也不要少一个条件。
- 默认一人称或第二人称只承担叙事视角，不能虚构学生经历、实验结果或历史事实。

建议字数只是节奏校准，不是硬凑字数：

| 时长 | 常见中文口播量 |
|---|---|
| 20-30 秒 | 70-130 字 |
| 45-60 秒 | 150-240 字 |
| 75-90 秒 | 240-360 字 |

遇到公式、陌生术语或需要停顿时取区间下限。

### 5. “像小论文”而不“像套模板”

小论文感来自“有一个观点被逐步论证”，不是来自堆书面连接词。优先选择一种主线：

- **误解纠正型**：大家以为 A -> 真正决定的是 B -> 机制 -> 边界。
- **过程追踪型**：一个量/对象从起点经过若干环节 -> 每步发生什么 -> 最终结果。
- **两难辨析型**：两个看似冲突的判断 -> 比较标准不同 -> 各自在什么条件下成立。
- **专业看日常型**：日常现象 -> 专业概念 -> 机制解释 -> 回到现象。
- **知识串联型**：共同问题 -> 2-4 个知识点各管一段 -> 汇成同一判断。

不要每次都从“人生就像……”开头，也不要强行把工程量、历史事件或公式写成恋爱隐喻。

### 6. 输出结构

默认给学生的是干净口播正文，随后保留一个很短的学习解码：

```text
口播正文：……

知识锚点：术语甲；关系乙；边界丙。
听完别复述文案，只回答：……？
```

用户要直接配音时，可另给“停顿版”，用换行表示停顿；不要在正文里塞大量括号、星号或舞台说明。

## 三、声音样本校准

### 1. 只处理声音

用户说明画面无关时，不做截图、画面识别、字幕 OCR 或视觉风格分析。先确认附件中存在真实视频/音频文件，再运行：

```text
python scripts/extract_reference_audio.py 输入视频 --output 参考音频.wav
```

脚本只提取音轨并转成 16 kHz、单声道 WAV。随后用可用的本地语音转写工具生成带标点文本；没有转写能力时，保留音频并请用户补传原视频或转写文本，不能根据封面猜内容。

### 2. 建立声音风格卡

从转写和音频中只抽象可迁移特征：

```text
开头方式：
中心观点出现位置：
平均句长与长短句比例：
轻停顿/重停顿分布：
重复、反问、转折的频率：
专业词密度：
情绪曲线：
结尾方式：
最值得迁移的两个结构特征：
不应照搬的特色长句：
```

只学习“怎么推进、怎么停、怎么把术语送进听众耳朵”，不模仿可识别的声音身份，不复制样本的连续特色表达，不把样本事实带入新课程。

### 3. 样本不足时

- 只有封面或截图：明确“没有声音证据”，使用通用口播框架，等待音频校准。
- 音频太短、噪声大或转写不确定：只采用可确认的节奏特征，并标注不确定项。
- 样本含背景音乐：只研究语音文本和停顿，不把音乐情绪误判为文案情绪。

## 四、发送前质量门

### 口诀五问

1. 标准词、符号、条件和顺序都保留了吗？
2. 每个节拍能唯一还原一个知识片段吗？
3. 连读两遍自然吗？
4. 去掉押韵后仍有知识意义吗？
5. 学生能脱离口诀回答一次吗？

### 口播六问

1. 能用一句话指出中心知识吗？
2. 专业概念真的参与了推理，还是只做装饰？
3. 至少有一条完整的“条件/原因 -> 变化 -> 结果”吗？
4. 修辞有没有制造错误、漏条件或抢走注意力？
5. 去掉生活故事后，知识骨架仍完整吗？
6. 结尾检索能检查理解，而不是只问“有没有共鸣”吗？
7. 有没有自己回答刚提出的学生检索题，或补入材料未给条件的额外结论？

任一关键项为否：回到知识骨架重写，不靠增加网络梗补救。

## 五、示例

### 口诀示例：资金等值换算

标准表述：先确定现金流时点和换算方向，再按跨越的期数进行计息或折现。

顺口记：**看时点，认方向；跨几期，换几期。**

映射：“看时点”对应现金流发生时间；“认方向”对应现值与终值的换算方向；“跨几期”对应 `n`；“换几期”对应计息或折现次数。口诀没有替代具体公式。

### 知识小论文示例：关键线路

项目最怕的，不是某项工作看起来慢，而是它一慢，整个完工日期就跟着往后走。网络计划把所有工作连成路径，每条路径都有自己的总持续时间；其中总持续时间最长的那条，就是关键线路。它像项目的总进度尺，关键工作若没有可用时差，晚一天，项目就可能晚一天。所以判断关键，不能只盯着单项工期长不长，而要看它落在哪条路径、这条路径有没有余量。

知识锚点：路径总持续时间；关键线路；时差。  
检索：为什么“工期最长的单项工作”不一定是关键工作？
