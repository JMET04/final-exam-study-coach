# 学习记忆库、复盘与考前复习页

目标：让学习助手记住学生真实学习轨迹，包括错题、疑问、作业批改、掌握度、复测安排和考前复习页。下次学生问同一知识点时，先检索历史，再用“你之前卡在这里”的方式讲解。

## 记忆对象

- **错题数据库**：题目、课程、知识点、题型、学生答案、正确答案、错因、正确规则、下次复测。
- **疑问数据库**：学生原问题、相关知识点、解释版本、是否解决、仍卡住的位置。
- **作业批改记录**：原图路径、批改图路径、教师依据、标注说明、需要复测的错误。
- **掌握度画像**：每个知识点的状态、最近表现、置信度、复习次数。
- **错因画像**：同一学生反复出现的符号混淆、概念偷换、步骤缺失、单位边界、审题错误等。

## 检索规则

当学生说“我不会/讲一个/考考我/这个知识点忘了”时：

1. 先查同课程同知识点的错题和疑问。
2. 如果没有精确匹配，查相邻知识点、同题型和同错因。
3. 讲解时必须连接历史记录，例如“你上次在有效应力这里主要漏了 u 的符号，所以这次先补这个”。
4. 如果历史记录很旧，先短测一次，不要直接假设学生仍然不会。

## 复盘节奏

- 新错题：当天 10 分钟内订正一次。
- 次日：不看答案复做或口述步骤。
- 3 天后：做变式题。
- 7 天后：混入同类题组。
- 考前：只回炉高频错因、未解决疑问和低置信度知识点。

## 当前会话回炉队列

在一次带练会话中，学生答错、答不出、混淆或自述忘记的记忆型知识点，必须临时加入“当前会话回炉队列”。即使暂时不写入长期 JSON，也要在对话中持续使用。

每个队列项至少记录：

- 课程与知识点。
- 学生刚才的错误答案或“不会”。
- 正确核心词。
- 错因类型：忘记、混淆、张冠李戴、核心词缺失、阶段错位、主体对象错位。
- 下次回炉触发：至少隔 6-10 个新小题或 10-20 分钟、本学习块末尾、下次恢复、考前。

当会话继续推进时，必须主动把队列项混入后续复习，不等用户提醒，但要保护主线推进。单个学习块中，新内容推进占 70%-85%，错点回炉占 15%-30%；同一知识点 15 分钟内最多回炉 2 次，除非学生主动要求。学生连续两次答对后，可把该项从当前高优先级队列降级；如果再次答错，重新提高优先级。

## 状态更新

优先使用 `scripts/update_learning_memory.py` 写入结构化状态。最低要求：

```bash
python scripts/update_learning_memory.py learning_memory.json --course 土力学 --concept 有效应力 --kind wrong --prompt "总应力和有效应力关系" --student-answer "符号忘了" --correct-answer "sigma = sigma' + u" --error-type "符号混淆" --fix-rule "看到孔隙水压力先写 sigma' = sigma - u"
```

脚本应同步生成：

- JSON 数据库：给后续检索、重排计划、考前复习页使用。
- Markdown 摘要：给人阅读。
- checkpoint：上下文压缩后先读，避免忘记进度。

## 考前复习页

当用户说“考前提醒”“考前复习页”“临考清单”“最后看一眼”“我怕错什么”“不熟点汇总”等类似话时，必须生成考前复习页，而不是只给泛泛复习建议。运行：

```bash
python scripts/build_pre_exam_review_page.py learning_memory.json --course 土力学 --exam-date 2026-06-24 --output pre_exam_review_page.md --json-output pre_exam_review_page.json
```

考前复习页必须同时包含：

- **高频错题/错因**：来自错题和作业批改，按次数、低置信度、未解决状态和临近复测排序。
- **不熟点/低置信度**：来自疑问、掌握度记录、知识点统计和用户自述“还不熟”。
- **正确规则**：每个错因压缩成一句“下次先做什么”。
- **1 分钟自测**：考前可闭卷完成的小任务。
- **最后 15 分钟检查清单**：把最高优先级错点和不熟点合并成可执行清单。
- **考前禁止事项**：提醒学生不要临时铺开整本书、不要只看答案、不要牺牲考试状态。

如果学习记忆库为空，先做诊断小测或录入最近错题；不要伪造学生历史错题。

## 考前易错提醒

如果用户只要求“易错提醒”或“临考提醒我别错什么”，可运行更窄的错题提醒脚本：

```bash
python scripts/build_exam_mistake_reminders.py learning_memory.json --course 土力学 --exam-date 2026-06-24 --output exam_mistake_reminders.md --json-output exam_mistake_reminders.json
```

它只聚焦错题和作业批改；如果用户还提到“不熟”“没把握”“最后复习页”，应改用 `build_pre_exam_review_page.py`。

## 讲解输出模板

- **历史连接**：你上次在哪个题/哪个疑问卡住。
- **这次先补什么**：只补最短必要前置。
- **一句话规则**：把错因压成可背规则。
- **小测**：1-3 题，先检索再解释。
- **记忆更新**：根据答题结果更新掌握度和复测时间。
