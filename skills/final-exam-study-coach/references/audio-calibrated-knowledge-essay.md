# 声音样本校准：戳心知识口播

> 先读 `emotional-knowledge-monologue.md`。这条样本的核心不是“像论文”，而是用准确专业机制说中恋爱或生活里的具体人情瞬间；专业知识负责搭台，人物段和那句克制的真相负责抓人。

## 样本来源与处理边界

- 样本：用户提供的 77.58 秒视频音轨。
- 处理：只提取音频并转写；未查看、识别或使用视频画面。
- 主题：机械制造中的滚花加工。
- 高置信度专业骨架：滚花不是切削；带齿纹的滚花刀压在旋转工件表面，把交错齿纹压进金属；光滑外圆形成纹路；目的在于增加摩擦、降低握持时打滑。
- 个别代词和结尾动词存在语音识别歧义；只用于判断文案结构，不把不确定字句写成教材事实。

## 样本真正好用的地方

这条口播真正抓人的不是论文结构，而是中段那种“像在说专业知识，其实突然说中了某段关系”的感觉。一条专业关系同时承担“知识解释”和“情绪叙事”：

1. 前 22 秒连续讲专业定义、加工方式、表面变化和功能目的。
2. 用一句“我的意思是”把专业段与人物段连接起来。
3. 整段只用“滚花”这一套核心隐喻，不连续换场景。
4. 人物段逐项复用专业动作：
   - “不是切掉材料”对应“没有拿走对方什么”；
   - “滚花刀施压”对应“在心里最冷的地方留下作用”；
   - “光滑外圆出现纹路”对应“人被关系留下痕迹”。
5. 情绪段结束后重新回到“滚花加工”的标准解释，让知识成为最后落点。

所以，它不是“术语装饰鸡汤”，而是：

```text
专业机制 A -> B -> C
人物故事 a -> b -> c
其中 a、b、c 必须分别对应 A、B、C
```

## 默认模板：知识先行回环型

样本的专业段和人物段语言边界很清楚：专业段说滚花刀、工件、齿纹和摩擦；人物段不让角色念机械术语，而是用靠近、打乱、留下纹路完成映射。生成时必须保留这种分层，不能把变量塞进人物对白。

用户说“像这个视频一样写”时优先使用：

这里的“人物/日常逐项映射”必须形成一个最小叙事单元：有明确对象、有一个对应专业动作、有由该动作引起的变化，再用一句克制的转折收住。只说“可以想象成两个人搬箱子”而没有事件推进，属于解释性类比，不算参考视频式小论文；应继续写出动作和变化，或明确降级为普通通俗解释。

**生活场景硬门**：用户明确说“像参考视频一样”时，专业段之后必须另起一个可想象的日常或人物场景，通常用 2-5 个短句完成“谁/什么 -> 做了什么 -> 谁/什么发生怎样的变化 -> 一句克制余味”。不能只让“应力来到土体”“项目在赛跑”等专业对象拟人化，也不能只补一句普遍感慨。场景中的每一步都要能回指专业动作、变化或结果；找不到稳定映射时，直接说明本知识更适合普通解释，不伪装成小论文。

合格的最小场景不是固定文案，可以像这样搭骨架：两个人抬同一只箱子，其中一人接住更多，另一人肩上的实际份额随之改变；随后马上回到“总量没有消失，承担份额发生了变化”这一专业关系。不要照抄句子，只迁移逐项对应的结构。

```text
1. 点名知识点
2. 用“不是……而是……”划清概念边界
3. 讲动作/条件如何导致变化
4. 讲变化解决什么实际问题
5. 用一句自然桥梁切到人物、校园或日常场景
6. 让场景逐项复现专业机制，不另起第二套比喻
7. 给出一个克制的转折或余味
8. 回到知识点，重述最小标准结论
9. 另起一句检索题，检查学生能否脱离文案回答
```

桥梁句不固定复制“我的意思是”。根据语气自然选择：

- “换到我们身上，其实也一样。”
- “把这件事放进生活里，你会发现……”
- “所以我总觉得，这个知识点说的不只是一件工件。”
- 直接承接，不使用显式桥梁。

如果这些句子读起来像模板，应删掉桥梁句，直接从专业结果转入场景。

## 另一模板：生活问题进入型

知识本身缺乏可视动作，或用户更需要先建立动机时使用：

```text
生活现象/问题 -> 直觉误区 -> 专业概念 -> 机制 -> 回扣现象 -> 标准结论
```

不要强行把所有知识都写成人物关系。选择模板时先问：这个知识是否存在可以稳定映射的“动作、变化、结果”？有则优先知识先行回环型；没有则使用生活问题进入型或普通解释。

## 声音节奏指纹

从音轨和时间戳得到的可迁移特征：

- 样本先讲滚花加工，再进入人物叙事；要求同类结构时不得把恋爱对白放在专业知识之前。
- 人物段以旁白推进，不是角色轮流念台词，更不会让人物说机械术语。

- 总长约 78 秒。
- 专业段约占前三分之一，人物映射段约占中间一半，结尾回题约占最后六分之一。
- 多数语义单元只占 1-2 秒，常见为 5-14 个汉字；一个动作或判断独立成句。
- 口播基本连续，背景音乐使整段没有明显长静音；节奏来自短句换行，不来自频繁停顿。
- 情绪曲线为“冷静讲知识 -> 轻微升温 -> 克制转折 -> 冷静回题”，不是一路煽情。
- 关键术语在开头与结尾各出现一次以上，增强回忆线索。

生成时不必机械复制时长比例，但要保留：

```text
知识先站稳 -> 情绪再进入 -> 最后把知识带回来
```

## 写作检查

### 逐项映射表

成稿前先在内部建立：

| 专业事实 | 文案映射 | 是否保持方向与边界 |
|---|---|---|
| 动作/条件 | 场景中的对应动作 | 是/否 |
| 中间变化 | 场景中的对应变化 | 是/否 |
| 功能/结果 | 场景中的对应结果 | 是/否 |

有一项为“否”，就删掉该映射，不用感性语言掩盖。

额外检查“说了”和“做了”是否混淆：样本中的滚花刀是真的施压并留下纹路，所以人物段也必须有实际靠近、打乱或留下变化；一句口头承诺本身不能映射为已经发生的专业作用。

逐项映射只能使用已经确认的专业机制。若源材料只给出静态关系，就不要借故事擅自补出随时间演化、排水条件、破坏结果或价值判断；确需扩展时先写明成立条件。

### 生硬检测

命中任一项必须重写：

- 一句话同时塞入两个互不相干的专业概念。
- 比喻只能解释名词，不能解释动作、方向或因果。
- 连续三句都是排比、金句或“人生就像”。
- 人物故事比专业知识长很多，却没有回到标准结论。
- 结尾只追求“破防”，学生说不出知识点。
- 为了悲伤或浪漫，虚构公式条件、工程作用或历史事实。
- 结尾提出检索题后，立刻替学生把答案也写出来。
- 把普通“像 A 一样”的静态类比标成参考视频式小论文，却没有对象、动作、变化和回题。
- 用专业对象拟人化或一句空泛感慨代替独立生活场景；读完找不到“谁做了什么、谁发生了什么变化”。

## 教学落点

播放或朗读小论文后，不问“感不感动”。从以下检索中选一个：

- “去掉故事，刚才的专业过程分哪三步？”
- “故事里的哪个动作对应原知识中的哪个条件？”
- “这段文案有没有漏掉适用边界？”
- “现在只用老师的术语，把结论重说一遍。”

学生只能复述人物故事时，说明娱乐被记住、知识没有被记住；立即回到标准表述和图示。
