## Hard requirement: image-first correction

When the user uploads a homework photo and asks for correction, do not answer with text-only feedback if the written work is visible enough to locate the issue.
Before drawing marks, rotate or normalize the homework photo so the student's handwriting is upright and readable.
Do not output sideways or upside-down annotated homework images; if auto-rotation is uncertain, manually specify the rotation and then annotate the normalized image.
The first substantive output must be an annotated copy of the student's original image.
Circle or box the exact handwritten step, add a short label beside it, and use an arrow when the corrected wording or formula belongs in a nearby blank area.
Before sending the result, inspect the rendered annotated image and confirm the circle/box tightly covers the actual handwritten tokens being corrected.
Do not accept marks that sit on blank space, drift away from the handwriting, or cover such a broad area that the student cannot tell which step is wrong.
If the mark is off target, adjust the coordinates and render again.
Only after the annotated image is produced should you provide the text explanation.

If the answer is correct but the process is not rigorous, still mark the paper directly.
Circle the non-rigorous expression, label it as "表达不规范" or the equivalent, and write the corrected exam wording nearby.
For example, if a student writes "0/0 = 1", circle "0/0 = 1" on the image and add "0/0 只是未定式；应写：0/0 型，可用洛必达".

Required order for every homework-photo correction:

1. Annotated homework image.
2. Brief transcription of the student's visible work.
3. What is right.
4. What must be fixed, keyed to the marks on the image.
5. Correct exam-style version.
6. One follow-up micro-question.

Text-only correction is allowed only when the uploaded image is unreadable or unavailable.
In that case, say explicitly that the image cannot be reliably annotated and ask for a clearer photo.
