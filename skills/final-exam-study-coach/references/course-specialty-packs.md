# 课程专项包

这些专项包用于把通用复习教练压成“懂这门课的期末教练”。如果用户课程属于下列方向，优先参考对应包；如果老师范围不同，以用户材料为准。

## 高等数学

**一句话核心**：用极限、导数、积分描述变化，并把复杂变化局部化、累积化、可计算化。

**主线**
函数与极限 -> 导数/微分 -> 积分 -> 级数/多元/微分方程。

**高频题型**
- 极限计算：等价无穷小、洛必达、夹逼、泰勒。
- 导数应用：单调性、极值、凹凸、切线。
- 积分计算：换元、分部、定积分应用。
- 多元：偏导、梯度、极值、二重积分。

**常见错法**
- 看到极限只会套洛必达，不会判型。
- 积分换元边界不改。
- 多元极值漏约束或漏判定。

**动画模板**
- 割线变切线。
- 中值定理/柯西中值定理：端点割线与区间内某点切线平行。
- 洛必达法则：函数值之比与导数之比的变化速度对照。
- 泰勒公式：多项式逐阶贴近原函数。
- 小矩形累积成面积。
- 等高线与梯度方向。

## 线性代数

**一句话核心**：用向量和矩阵描述空间变换，核心是结构能不能被拆开、简化、求解。

**主线**
矩阵运算 -> 方程组 -> 向量空间 -> 特征值/特征向量 -> 二次型。

**高频题型**
- 行列式与秩。
- 线性方程组解的结构。
- 特征值、特征向量、对角化。
- 正交、二次型化标准形。

**常见错法**
- 把行变换能不能用于特征值计算混淆。
- 对角化条件只背公式，不会看特征空间维数。
- 基础解系和通解写不规范。

**动画模板**
- 网格被矩阵拉伸/旋转/剪切。
- 特征向量方向不变。
- 行变换保持解集。

## 概率论与数理统计

**一句话核心**：在不确定中建模、更新判断，并用分布和统计量做推断。

**主线**
事件概率 -> 条件概率/独立 -> 随机变量与分布 -> 数字特征 -> 大数/中心极限定理 -> 参数估计/检验。

**高频题型**
- 条件概率与贝叶斯。
- 离散/连续分布计算。
- 期望、方差、协方差。
- 正态、二项、泊松、指数分布。
- 置信区间、假设检验。

**常见错法**
- 混淆 P(A|B) 和 P(B|A)。
- 连续型概率把点概率当面积。
- 不知道何时用哪个分布。

**动画模板**
- 样本空间筛选与概率质量重分配。
- 直方图逼近密度曲线。
- 样本均值逐渐稳定。

## 数据结构

**一句话核心**：为不同操作选择合适的数据组织方式，让程序在时间和空间上更高效。

**主线**
复杂度 -> 线性结构 -> 树 -> 图 -> 查找/排序 -> 哈希/堆/并查集。

**高频题型**
- 时间复杂度分析。
- 栈/队列/链表操作。
- 树遍历、二叉搜索树、堆。
- BFS/DFS、最短路、拓扑排序。
- 排序过程与稳定性。

**常见错法**
- BFS/DFS 容器和访问时机混淆。
- 递归不会画调用栈。
- 排序只背结论，不会模拟过程。

**动画模板**
- 队列/栈状态变化。
- 图遍历访问顺序。
- 排序比较与交换。
- 动态规划表格填充。

## 大学物理

**一句话核心**：用少数守恒和变化规律解释力、运动、场、波和热过程。

**主线**
运动学 -> 牛顿定律 -> 能量/动量/角动量 -> 振动波动 -> 电磁学 -> 热学/近代。

**高频题型**
- 受力分析与运动方程。
- 能量守恒/动量守恒。
- 电场、电势、电路。
- 简谐振动和波。

**常见错法**
- 受力图漏力或方向错。
- 能量法和牛顿第二定律混用不清。
- 电势/电场方向混淆。

**动画模板**
- 受力分解和加速度方向。
- 电流路径和电容充放电。
- 振动相位变化。

## 电路

**一句话核心**：把电压、电流、元件关系和网络约束组合起来，求系统如何分配能量和信号。

**主线**
欧姆/基尔霍夫 -> 等效变换 -> 一阶/二阶动态电路 -> 正弦稳态 -> 频域。

**高频题型**
- KCL/KVL列方程。
- 戴维南/诺顿等效。
- RC/RL暂态。
- 相量法和功率。

**常见错法**
- 参考方向没统一。
- 初始值/稳态值搞错。
- 相量和时域混写。

**动画模板**
- 电流路径高亮。
- 电容充放电曲线。
- 相量旋转。
