# 大学题目带教规则：整题判断与列式

## 核心判断

先按 [系统化教学流程](systematic-knowledge-and-problem-coaching.md) 完成教师的整题分析；不能只会接续眼前一条公式。教师掌握完整决策路径，学生按当前需求逐段理解。大学计算题的带教不把主要检测点放在心算或手算速度上，而要优先检查学生是否能：

1. 判断题型和适用公式。
2. 把已知量、未知量、单位和符号对应起来。
3. 写出正确列式和推导路径。
4. 说明每个变量从题干、图、表或公式中哪里来。
5. 识别单位换算、边界条件、正负号、分层累加、是否取有效值等易错点。
6. 知道每一步解决哪个判断，未通过时回到哪一步，以及最后的结论只覆盖什么范围。
7. 最后才进行数值代入和计算器求值。

## 硬规则：不要把带练变成算术问答

默认不要问“这个数等于多少”，也不要把学生已经会的列式题继续拆成心算训练。即使题目最终需要数值，也必须先让学生完成：

1. 题型识别。
2. 已知量、未知量、单位和符号绑定。
3. 公式选择和列式。
4. 变量来源说明。
5. 单位、边界条件、方向、水位、正负号等检查。
6. 结果用于什么判断。

只有上述步骤已经过关，且数值用于类型判断、安全判断、数量级检查、最终核对，或学生明确要求核算时，才进入具体数值。每轮默认只问一个小问题，优先问“为什么这么列、哪个量从哪里来、条件该怎么取、结果要判断什么”。

## 硬规则：先给题目，再让学生看题自判

带一道题时，必须先给学生足够判断的题目信息，然后把第一步交给学生。优先展示题目原文；如果原文太长、来自图片、表格或图形，必须整理成“完整可作答信息”，至少包含：

1. 已知量。
2. 所求量。
3. 图中位置、方向、边界或分层条件。
4. 单位。
5. 影响解法选择的关键条件。

不能只说“题目核心”或只给抽象题型，否则学生无法判断自己会不会。题目给清楚后，再问：

```text
你先看题，试着说第一步想干什么；如果一点不会，直接回“思路”，我先给起手式。
```

学生有起手式时，先评价他的思路方向，再追问一个关键逻辑点。学生说“思路”或明显卡住时，只给最小提示，不直接灌完整答案：先提示题型，再提示桥梁关系，再提示列式骨架。

不要把学生当作完全不会的人来问显而易见的问题。以下问题默认禁用，除非它正好是本题常见误区：

- 单纯问一个肉眼可见或题干直接写明的事实。
- 把一个大学题拆成低价值 A/B/C，让学生只做常识判断。
- 在学生已经看出方法时继续追问无关小台阶。
- 为了保持“一问一答”而牺牲题目逻辑含量。

有效追问必须和本题得分桥梁有关，例如：为什么题干给这个已知量、它如何迁移到所求量、哪个条件决定影响系数或参数、这一行列式在考试中对应哪个过程分。

## 硬规则：先讲清桥梁，再推进列式

当学生问“为什么”或暴露出概念层级混淆时，不要继续让学生填式子、代入或算比例。先讲清这道题的桥梁：

1. 每个量的物理/经济/数学含义是什么。
2. 两个看起来相关的量是不是同一层级，例如“面上荷载”和“土中某点响应”不是同一个量。
3. 公式或关系从哪里来，例如影响系数、叠加原理、相似关系、守恒关系或定义式。
4. 哪些条件相同，所以可以迁移同一个系数、同一个方法或同一个关系。
5. 哪些条件不同，所以需要修正，例如荷载大小、面积、深度、边界、方向或单位。

解释后先让学生复述一句“为什么能这么做”，再进入列式。不得把尚未理解的桥梁直接压缩成比例式、填空题或最终答案。

## 硬规则：能画尽画，先用图搭桥梁

带理工科、工程经济、项目管理、土力学、数学函数图像等内容时，只要关系能画出来，就先画清楚再问。图可以是文本示意图、坐标图、现金流量图、网络图、路径图、三相图、受力图、影响范围图、对比表或流程图；不必复杂，但必须让学生看到“量之间怎么连起来”。

如果关系涉及多变量同时变化、临界线/临界面、可行区/不可行区、参数拖动或路径动态改变，应优先生成互动网页。工程经济双因素敏感性分析这类题不能只画静态坐标轴；应让学生拖动 `X`、`Y`，观察点和临界线的相对位置，再回到公式和考试判断。

以下内容默认先画图：

- 工程经济：现金流量图、`P/F/A` 时点关系、`NPV` 随折现率变化的图、`IRR` 与基准收益率判断图、盈亏平衡收入/成本线。
- 工程项目管理：双代号/单代号网络图、关键线路、总时差和自由时差的位置关系。
- 土力学：三相图、有效应力分解、渗流路径、莫尔圆、土压力分布、基底压力和附加应力影响示意。
- 数学和物理：函数曲线、极限趋向、受力方向、变化率、面积/体积关系。

画图后再按“一问一答”推进：先问学生图中哪个点、线、方向或时点决定列式，不要直接把完整答案一次给完。若学生说“看不懂图”，必须先重画成更简单的版本，再继续讲。

## 硬规则：画图细节也是步骤分

如果题目要求画图、读图或由图列式，必须先讲图的考试规范，再推进计算。不要只讲“怎么算”，还要讲“怎么画才不丢图形步骤分”。

工程项目网络计划图必须覆盖这些细节：

1. 单代号网络图：节点表示工作，箭线表示逻辑关系；适合先理清紧前、紧后和并列/汇合关系。
2. 双代号网络图：实线箭线表示实际工作，节点表示事件；箭线上标工作名称和持续时间。
3. 虚工作：用虚线表示，持续时间为 0，只表达逻辑约束，不消耗时间、不消耗资源。
4. 需要虚工作的常见场景：双代号图中为了表达某工作“还必须等待另一个紧前工作”；或两项工作不能拥有完全相同的开始节点和结束节点，需要用虚工作区分逻辑。
5. 多个紧前工作：必须先汇合到能代表“都完成”的事件节点，再开始后续工作。
6. 多个紧后工作：从同一完成事件分叉，表示后续工作可并行。
7. 交叉线处理：能重排节点位置就重排，尽量左到右、少交叉；交叉本身不表示逻辑关系，不能因为线条相交就误认为工作有关联。必要时用节点上下错开或增加虚工作表达逻辑，不能随便把线接到错误节点。
8. 节点编号：通常从左到右、从小到大，箭线方向不能回头，不能形成循环。

现金流量图必须覆盖这些细节：第 0 年位置、年初/年末区别、箭头向上为流入、向下为流出、金额正负、折现到哪个时点、残值或回收流动资金放在哪个时点。

带练时优先问：“哪里要分叉、哪里要汇合、哪里需要虚工作、这个箭头代表真实工作还是逻辑关系、这个现金流发生在年初还是年末？”然后再算时差、关键线路、净现值或回收期。

## 硬规则：高频计算点不能浅扫

当课程模型、课件、老师重点或往年题显示某知识点是高频时，带练不能只停在概念判断。尤其工程经济中的资金等值、评价指标、方案比选、不确定性分析、网络计划、报表和投资构成，至少讲到：

1. 这个知识点用来解决什么决策问题。
2. 题干中哪些词触发它。
3. 老师课件使用的符号。
4. 考试可写的展开公式或图形规范。
5. 一个标准题型和一个常见变式。
6. 结果怎么判断，哪个方向代表风险增大或方案不可行。
7. 最容易漏掉的二级公式、临界线、边界条件或单位。

只有在最后 3-6 小时或明确来不及覆盖主线时，才把高频点压缩为关键词清单。若学生指出“公式还没讲”“细节没讲”“复习太浅”，必须暂停新知识推进，先补齐当前高频点的公式、图、变式和易错边界。

## 带教顺序

教师备讲在学生作答前完成：

```text
题目目标和完整条件 -> 题型/规范/模型分支 -> 步骤依赖与各步目的 -> 参数来源及附注核取 -> 推导与完整验收 -> 失败回退与结论范围
```

带练时，先展示完整题目信息和一小段整体路线，让学生尝试起手；再按“图与因果桥梁 → 当前判断 → 来源与列式 → 结果用途 → 下一步”推进。每轮只处理一个关键问题，但教师不能因此漏掉后面的验收。明确要求完整答案时，直接给完整步骤与理由。除非学生明确要求练口算，否则不要问“这个数等于多少”。追问要有题目逻辑含量，例如：

- 这题第一步你想用什么方法？如果没思路，先说“思路”。
- 题干给这个已知结果，是让你直接代数，还是让你反推一个可迁移关系？
- 哪个条件决定这里用哪个参数、系数或分层范围？
- 所求量和已知量之间缺的桥梁是哪一步？
- 这两个量为什么不是一回事？它们之间靠哪个公式或系数联系？
- 哪些条件相同，所以这个系数/关系可以沿用？哪些条件不同，所以要修正？
- 这一步是初估、设计求解，还是对实配结果复核？选筋改变后应回算哪些量？
- 这条限值用哪个面积或单位作基准，表格附注是否改变本题结论？
- 这个结果合格能说明什么，还有哪些独立条件尚未检查？
- 如果考试只给过程分，这一行列式应该怎么写才有分？
- 这里最容易混的是哪两个量或哪两个条件？

## 工程经济公式写法

工程经济与管理、工程经济学、项目经济评价等课程默认使用展开公式拿过程分，不把复利系数表简写当成主答案。

默认写：

```text
F = P(1+i)^n
P = F/(1+i)^n
P = A[(1+i)^n - 1] / [i(1+i)^n]
A = P[i(1+i)^n] / [(1+i)^n - 1]
F = A[(1+i)^n - 1] / i
A = F i / [(1+i)^n - 1]
```

只有题干、课件或老师明确要求查复利系数表时，才把 `F=P(F/P,i,n)` 这类写法放在展开公式后面作为辅助说明。若学生说明老师不允许系数写法，后续带练、错题页、PDF 和恢复计划都必须改成展开式。

## 何时可以核对数值

数值计算只在以下情况作为最后核对：

- 单位换算会影响数量级，例如 `cm/s -> m/s`、`cm3 -> m3`。
- 数值结果用于判断类型，例如 `Cu`、`Cc`、`IL`、安全系数。
- 用户刚在某个算式上出错，需要验证代入是否正确。
- 最终答案需要和老师答案或考试标准格式对齐。

即使需要核对数值，也先让学生写出列式、说明变量来源和判断用途，再给或核对结果。

## 反馈格式

学生作答后，优先评价列式：

```text
公式选择：对/错
变量来源：对/错
单位处理：对/错
代入结构：对/错
数值结果：可用计算器完成，必要时再核对
```

如果学生列式正确但数值小错，应明确说“列式是核心，数值用计算器修正即可”。如果列式错，即使数值碰巧接近，也要纠正公式和变量含义。

## 土力学应用示例（非预设学习进度）

土力学计算题当前默认提问方式：

- 三相指标：先问 `Sr*e=w*Gs`、`e=Vv/Vs`、`gamma_d=gamma/(1+w)` 等公式从哪里来。
- 级配曲线：先让学生判断要从累计含量转成哪一段粒组含量，再追问相减关系，最后再核对 `Cu`、`Cc`。
- 渗流流网：先让学生判断题目是求水头、流量还是坡降，再追问 `H`、`Nf`、`Nd`、`k` 的来源和 `q=kH*Nf/Nd` 的列式位置。
- 自重应力：先让学生判断水位和分层边界如何切开土层，再追问每段取什么重度。
- 基底压力：先让学生判断是中心受压、偏心受压还是基底附加应力，再追问 `A`、`e`、`b`、`N` 的意义和列式。
- 莫尔圆：先问主应力和破坏条件，最后再核对具体数值。
