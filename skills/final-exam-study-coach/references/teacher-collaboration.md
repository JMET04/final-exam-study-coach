# 教师与课程协同

目标：把学习助手扩展到学校场景，帮助老师统一课程进度、发现共性问题，并为学生提供课前预习和课后答疑。默认保护学生隐私，只输出匿名聚合结果，除非学校和学生明确授权实名共享。

## 课前

1. 读取老师教学安排、课件目录、课堂目标和作业安排。
2. 为学生生成 10-20 分钟预习任务：
   - 本节课要解决的核心问题。
   - 必要前置概念。
   - 2-3 个预习检查题。
   - 听课时要特别抓的关键词或步骤。
3. 对基础薄弱学生，先补最短前置知识，不提前塞完整章节总结。

## 课后

1. 收集学生自评、疑问、错题和作业批改结果。
2. 将问题归类为：
   - 概念没懂。
   - 公式/步骤不会用。
   - 计算或单位错误。
   - 审题错误。
   - 表达和答题格式问题。
3. 对学生个人给出补救任务。
4. 对老师输出匿名班级报告。

## 教师报告

教师报告必须包含：

- 本阶段覆盖的课程进度。
- 学生整体掌握度分布。
- 高频错因 TOP 5。
- 未解决疑问 TOP 5。
- 建议老师下节课回讲的 3 个点。
- 建议布置的分层练习。
- 数据来源和隐私模式。

可使用 `scripts/build_teacher_progress_report.py` 从学习记忆库生成报告。

## 隐私边界

- 默认 `anonymous`：只给聚合统计，不出现学生姓名、照片、原始作业图片。
- `named` 只能在用户明确要求且符合学校授权时使用。
- 对老师报告不要输出学生的私密聊天内容，只输出学习问题、知识点和建议教学动作。
