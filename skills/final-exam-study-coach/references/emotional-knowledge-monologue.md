# 戳心知识口播：专业知识只是搭台，人心才是戏

## 执行摘要：恋爱口播先过这四步

这四步优先于后文所有修辞建议：

1. **专业段**：原样写出知识、公式、条件和因果。
2. **纯动作链**：把专业机制暂时去掉术语，只留下动词和方向，例如“总量没变 -> 有人实际接住一部分 -> 他松手后 -> 剩余承担增加”。
3. **生活段**：只按这条动作链写一个真实恋爱镜头，4-8 个短句；其中不得出现源公式、变量、专业术语或给道具挂牌。

   写完立刻建立逐项对照：专业第 1 节点对应生活第 1 节点，专业第 2 节点对应生活第 2 节点，专业结果对应生活结果。节点数至少 3 个，方向必须一致。只有情绪相似不算同形。
4. **揭回知识**：给出唯一戳心句后，再恢复老师术语重说结论，只留一个来源材料能够回答的问题。

发送前把正文切成“专业 / 生活 / 回题”三段。扫描生活段：只要出现来源中的变量、公式、专业名词，或出现“关系里的某某应力/线路/成本”这种换皮术语，整段重写。扫描检索题：只要包含来源材料没有给出的新性质、新方向或新指标，也重写。

**坏例子**：把鲜花叫 `σ`，把对方叫 `u`；让人物说“你增加了我的总应力”；把“宝宝别怕”当成已经发生的分担。  
**另一种坏例子**：专业机制讲实际分担，却写成打游戏、点赞、已读不回或失去耐心。这些片段可能戳心，但没有“谁实际承担了多少”的变化，换到任何关系知识都能用。  
**合格形状**：他曾真的替你完成一部分任务，所以你肩上的事少了；后来他离开，没有新增任务，但原来被接住的那部分重新落回你身上。整个生活段不说任何专业词，回题时才指出它对应“总量不变、分担减少、剩余承担增加”。

## 先纠正名称

用户口中的“知识小论文”只是触发词，不代表成品要有论文腔。真正目标是：**借一个准确的专业机制，调侃恋爱、友情、室友、考试、工作或家庭里大家经历过却不太会说出来的瞬间，让学生先被说中，再把这种感觉反向绑定到知识点。**

成品应像一段可以直接念的短视频口播，而不是定义加例子，也不是专业名词装饰的鸡汤。

默认吸引力排序：

1. 人情观察是否具体、好笑或戳心。
2. 生活情境与专业机制是否严丝合缝。
3. 专业知识是否准确、能被带回考试。
4. 文案是否有短视频口语节奏。

这里的排序不允许牺牲准确性。技术准确是门槛，不是卖点；情绪共鸣是卖点，不是改写事实的许可证。

## 一、先找“矛盾形状”，不要先找恋爱梗

写之前先把知识压成一个带方向的关系：

```text
谁/什么作用于谁 -> 中间发生什么 -> 最后改变什么
表面看起来是什么 -> 实际决定因素是什么
什么量不变 -> 什么量改变 -> 结果往哪边走
跨过什么门槛 -> 状态为什么突然改变
哪一段拖延 -> 为什么影响整个结果
投入了什么 -> 同时放弃了什么
```

再从下表选择同形的人情矛盾。不是按名词相似，而是按“动作、方向、因果”相似。

| 专业机制形状 | 可选生活矛盾 | 常见情绪 |
|---|---|---|
| 分担、传递、剩余承担 | 有人接住你的一部分；承诺帮忙却没有伸手 | 托举、失落、嘴硬 |
| 阈值、临界、越界 | 暧昧很久；一句话后关系改变；底线被反复试探 | 紧张、清醒 |
| 滞后、累积、不可逆 | 当时没反应；后来才发现留下痕迹 | 后知后觉、遗憾 |
| 衰减、损失、阻力 | 话传着传着变了；热情在等待里耗掉 | 自嘲、疲惫 |
| 路径、瓶颈、关键环节 | 看似不起眼的人或事卡住全部进度 | 调侃、无奈 |
| 机会成本、取舍 | 为一个“也许”放弃明确的选择 | 清醒、心酸 |
| 平衡、反馈、相互作用 | 一个人不断靠近，另一个人始终不回应 | 失衡、清醒 |
| 表面变化、内部承载 | 看起来没变，真正承担的位置已经不同 | 克制、余味 |

找不到同形矛盾时，不硬写恋爱。改用宿舍、赶作业、课程小组、求职、健身、家庭沟通等更匹配的场景，或降级为普通有趣解释。

### 同形不是同词

- 分担：必须有人真的接手、完成或承受一部分，随后承担份额发生变化。
- 阈值：必须有一个明确前后状态，以及跨过边界的动作。
- 取舍：必须出现选择 A 与因此失去的最佳 B。
- 瓶颈：必须出现多环节依赖，以及一个环节让后续无法继续。
- 滞后：必须出现作用已经发生、结果稍后才显现。

如果生活段只出现“压力、失去、等待”这些泛词，却没有对应结构，不通过。

### 变化必须有真实基线

写“后来越来越少”之前，先给出过去真的做过什么；写“停止分担”之前，先给出曾经实际接手过什么。‘以前总说会帮忙，后来不说了’只描述话语变化，不等于承担变化。最后检索题沿用故事里的同一箭头方向，使戳心句成为公式变化的回忆线索。

## 二、必须先选一个“人心落点”

一条口播只选一个落点，不能同时写暗恋、友情、原生家庭和职场。常用落点：

- **错过**：不是不喜欢，是等到条件变了才开口。
- **单向承担**：两个人的事，最后总有一个人在收拾残局。
- **若即若离**：不拒绝，也不真正靠近，让人一直停在临界点前。
- **后知后觉**：人走时没带走什么，后来才发现留下的变化不可逆。
- **沉没与取舍**：舍不得的未必是对方，可能是已经投入的自己。
- **被接住**：真正让压力变轻的不是安慰，是有人实际承担了一部分。
- **群体协作**：群里人人都说“收到”，真正的关键线路只有一个人在走。
- **考试自嘲**：知识点见过很多次，真正承担分数的那次一次没写对。

选择标准不是“最伤感”，而是“最像这个专业机制”。

## 三、参考视频式七拍结构

### 双层语言原则

整段有两种语言，但不能混在同一句里：

- **专业语言**：术语、公式、条件、方向，只出现在开头知识段和结尾回题段。
- **生活语言**：聊天、等待、承诺、点赞、离开、承担，只出现在人物/日常段。

人物不会在约会时说‘你是我的 `u`’，组员也不会在群里自称‘关键工作’。把符号贴在鲜花、箱子、奶茶等道具上，只是换皮教具，不是人情口播。正确做法是让生活动作自然复现机制，等生活真相说完，再由旁白回到专业词。

### 第 1 拍：冷静点题

用 2-4 个短句讲清专业对象、动作和结果。必须保留老师原词、原符号和条件。不要一上来就说“爱情也是这样”。

用户明确要求参考样本同类结构时，第一句直接出现知识点名称或来源公式；生活镜头不得先于专业段。普通调侃型可以从场景开门，但仍必须在中段完整讲清机制并在结尾回题。

### 第 2 拍：指出反直觉处

用一句“不是……而是……”或同类边界，给后面的情绪反转埋钩子。这个边界必须真的是专业边界。

### 第 3 拍：一刀切进生活

不用长转场。可以直接落到一个具体镜头：

- 聊天框里那句删了又打的话。
- 小组群里五个人同时回复“收到”。
- 对方说“有事找我”，真正有事时却一直没出现。
- 明知道答案，却在考场上把公式写成了另一种。

镜头必须能看见动作，不能只写“有些人”“后来才懂”“人生就是这样”。

优先使用旁白式微型叙事；直接对白通常 0-2 句，只用来呈现最关键的承诺或反差。连续一问一答的男女对话容易像排练好的短剧，也会挤掉知识与余味，不作为默认写法。

### 第 4 拍：先轻轻调侃

先让人笑一下或产生熟悉感，再戳。调侃对象优先是共同处境或叙述者自己，不嘲讽具体学生，不做性别刻板印象。

例：

- “群里五个人都回了收到，项目也确实收到了五个‘收到’。”
- “你以为自己在等一个答案，其实对方早就把不回答当成答案。”

### 第 5 拍：动作和变化逐项映射

生活段至少复现专业机制中的两个节点，最好三个：

```text
专业动作 -> 生活中的动作
专业变化 -> 关系或处境中的变化
专业结果 -> 人真正感受到的结果
```

只相似一个名词不算映射。删掉专业词后，如果这段能无差别套在十个知识点上，就是泛用鸡汤，必须重写。

### 5.1 口头动作不等于专业作用

专业机制描述真实承载、耗时、投入、位移、阻力、收益或状态改变时，生活映射也必须发生真实行动。‘我陪你’‘收到’‘马上做’‘我替你扛’只是一句话，不能直接对应已经发生的分担、完成或投入。最自然的调侃往往来自这层反差：先写他说了什么，再写实际动作没有发生，最后说明真正的压力、工期或成本落到了谁身上。

内部核对两问：

1. 场景里谁真正做了动作，而不只是说了？
2. 这个动作变化是否与专业量的方向一致？

### 第 6 拍：给出一记“戳心句”

戳心句不是突然煽情，而是把前面的机制说成人话。通常只有一句，最多两句。它必须满足：

- 从专业因果自然推出，不是另起话题。
- 指向一个具体的人情真相，不是“人生很难”“要珍惜眼前人”。
- 读完能回想起专业关系，而不是只记得伤感。

合格形状：

- “压力没有消失，只是原来替你接住的人松了手。”
- “最贵的从来不是你为他花了多少，而是你为那个‘也许’错过了什么。”
- “真正拖住你的，未必是走得最慢的人，而是那件不完成、谁都走不了的事。”

这些只是结构示例，不能固定复用。

### 第 7 拍：冷静回题

情绪到最高处后立刻收住，用老师术语重说最小标准结论。最后只留一个检索问题，等待学生回答。

检索必须回到专业知识，例如判断方向、解释边界、复述机制或列出公式；不得问‘群里那个人是谁’‘你想起了谁’‘有没有共鸣’等只检查故事的问题。

大学复习默认检索思路和列式，不把最后一问降成无意义心算。优先问：为什么这样变化、哪项是判断依据、生活动作对应哪一段机制、应如何列出关系式。

检索不得越过材料证据：材料只给定义时问定义或辨析；给公式和条件时才问变化方向；只说某量‘控制’某性质时，不能自行补成单调增减关系。

## 四、情绪强度与篇幅

### 默认交付是口播，不是分镜表

成品默认只保留自然换行的口播正文，再另起一行放唯一检索问题。不要显示内部结构标签，也不要写“画面：”“旁白：”“知识卡：”“笑后戳一下：”。只有用户明确要求拍摄脚本、镜头表或字幕版时，才增加这些制作标记。真正的转折应由句子本身完成，不靠标题宣布。

参考样本的重点在中段人物叙事，不在“论文”。用户明确要求同类风格时，建议比例：

- 专业知识与边界：20%-30%。
- 生活镜头、调侃和情绪推进：50%-65%。
- 戳心句、专业回环和检索：15%-25%。

默认 45-80 秒，约 150-280 字。多数句子 5-16 个字；每句只做一个动作、判断或转折。调侃 1-2 处，戳心句 1 处，不要从头到尾连续“破防”。

用户只说“有趣一点”时使用轻调侃，不自动上爱情遗憾；用户说“像视频、戳心、恋爱小作文、知识小论文”时才提高情绪浓度。

**最低成稿量**：参考视频式完整版中，专业铺垫通常 2-4 句；生活镜头、调侃和变化至少 4-8 句；戳心句单独成句；随后 1-2 句回题。生活段短于专业段、只有一个泛泛类比或没有独立戳心句，一律不以“戳心知识口播”名义交付。

## 五、生活场景选择器

### 恋爱与暧昧

适合机制：分担、阈值、滞后、取舍、不可逆、失衡。  
镜头优先：等回复、删聊天框、嘴上承诺与实际行动、错过时机、离开后才显现的变化。  
禁区：把控制、纠缠、冷暴力、美化伤害写成浪漫；攻击某一性别；替真实人物下诊断。

### 友情与室友

适合机制：协作、资源共享、边界、反馈、摩擦、路径。  
镜头优先：借东西、值日、熄灯、占座、一起赶作业、嘴上说随便但谁都不决定。  
语气可以更轻，更适合调侃。

### 课程小组与工作

适合机制：关键线路、瓶颈、责任分担、边际贡献、风险。  
镜头优先：群里“收到”、最后一晚整合、人人都提意见但只有一个人改文件。  
戳心不一定伤感，也可以是精准的无奈。

### 考试与自我调侃

适合机制：记忆衰减、条件判断、路径依赖、机会成本、概率。  
镜头优先：考前都见过、考场认不出；公式背得很熟，条件一次没看。  
调侃学生处境，不贬低学生能力。

### 家庭与成长

适合机制：传递、反馈、约束、累积。  
只在知识高度匹配时使用，语气克制，不凭空制造创伤叙事。

## 六、四个反生硬测试

### 1. 换知识点测试

把专业词换成另一个概念，生活段是否仍完全成立？若是，说明太泛。

### 2. 具体动作测试

能否指出人物做了什么、没做什么，以及这导致了什么变化？若不能，说明只有情绪形容词。

### 3. 笑后再疼测试

是否先有一点熟悉或调侃，再出现一记克制的真相？如果第一句就大悲大痛，容易像廉价文案。

### 4. 回忆反向测试

只给戳心句，学生能否反推出专业机制？若不能，文案抢走了知识。

## 七、强制退回条件

命中任一项，整段重写：

- 开头是“人生就像”“爱情就像”，后面随便贴术语。
- 使用“小明、小红搬箱子”式教具人物，却没有真实人情矛盾。
- 让人物在生活对白中直接念公式、符号或专业术语，或给鲜花、箱子、奶茶等道具贴变量标签。
- 用“戳你一下、破防了吧”宣布情绪，却没有一句由具体动作推出的人情真相。
- 最后问题只问故事角色、个人经历或是否共鸣，没有检索专业知识。
- 用户只要口播正文，却输出大量“画面、旁白、知识卡”等分镜标签。
- 检索题要求判断材料没有给出条件或方向的专业结论。
- 只有“有些人、后来、遗憾、成长”等抽象词，没有聊天、等待、承诺、离开、承担等具体动作。
- 戳心句与专业因果无关，换任何知识点都能用。
- 把一句“收到、别怕、我来做”直接算成实际完成或分担，没有写真实行动是否发生。
- 生活段只有一句概括，没有至少两个可见动作和一个处境变化。
- 恋爱段比知识更长，却没有逐项映射或专业回环。
- 为了感动而改变符号、条件、方向、时间顺序或工程作用。
- 连续三句金句、连续两次强反转，或故意把语气写得过度悲壮。
- 把有害关系、纠缠、羞辱、控制或自我牺牲美化为深情。

## 九、发送前评分

每项 0-5 分，任一项低于 4 分就重写：

| 维度 | 5 分标准 |
|---|---|
| 专业准确 | 原词、符号、条件、方向完全保真 |
| 映射严密 | 至少两个机制节点逐项对应 |
| 场景具体 | 能看见人物动作和处境变化 |
| 调侃自然 | 像共同经历，不像硬讲段子 |
| 戳心程度 | 一句真相具体、克制、有后劲 |
| 口播节奏 | 短句可念，无论文腔与模板腔 |
| 学习回环 | 结尾回到标准知识并留下检索 |

这里特别强调：专业准确达到 5 分但“戳心程度”只有 2 分，仍然是不合格的参考视频式口播，不能因为知识没错就放行。

### 字符机械复核

把来源中的每条公式原样复制到成稿，再搜索容易被排版系统替换的字符：`′`、`’`、`−`。如果来源使用的是 `'`、`-`，成稿中出现这些替代字符就退回修正；看起来更漂亮也不允许。

## 十、微型示范：有效应力

以下只展示结构，不作为固定套话：

> 有效应力满足 `σ' = σ - u`。总应力并不全由土颗粒骨架承担，孔隙水压力先承担一部分，剩下的才真正落到骨架上。  
> 若总应力不变，原来替你接住一部分压力的人忽然松了手，那一份并没有消失，只是重新落回你肩上。聊天框还是那个聊天框，生活也没多一件事，可你就是突然觉得什么都更重了。  
> 所以有些人离开时没有带走什么，却会让你第一次知道，他原来替你承担过多少。  
> 回到土力学，控制土体变形和强度的是有效应力。现在只回答：当 `σ` 不变、`u` 减小时，`σ'` 怎样变化？

这个示范能成立，是因为“总量不变、分担减少、剩余承担增加”在专业段和生活段中方向一致。若材料没有给出变量变化关系，就不能照搬。
