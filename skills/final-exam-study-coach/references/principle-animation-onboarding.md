# 对话主讲，极简演示

先在对话解释当前问题的对象、用途、含义与关键因果，再按需主动展示合适资源。一次一个问题、一张图、一个变化、一个必要控件；用户未理解当前段前不自动连播。不把整节课或多变量总览塞进网页。

动画画面只有图形、必要短标注/读数及播放控件。讲解、观察提示、公式推导、前提、来源和关键帧说明保存在独立JSON或对话；不显示长解说和图下注释。新位置符号在实际图上标起止点、方向、单位和参考线。

区分固定量、共同决定的量和瞬态响应，不让控件暗示错误因果。图示比例与时间不冒充真实计算。没有动画能力时展示准确静态关键帧，不假装已经动态播放。

先复用符合当前条件的图，模型改后重新核公式、平衡和边界；实际打开、操作并观察后，才登记该版本浏览器通过。代码生成、模拟DOM、知识理解和全书动画覆盖互不替代。旧报告不证明新版本通过。既有动画生成脚本仅为候选模板，交付前须按本约束收敛并重新验收。

理解检查用条件完整的预测、因果或真实变式，不每动一个控件就问简单算术；学生困惑时核前提和模型，不重复播放代替解释。通用AI上下文只含当前知识点、单段、画面状态及用户疑问，不绑定API、不自动发送外部。
