孔隙比 e = Vv / Vs 0.00 孔隙体积与土粒体积相比。压密、沉降、密实度会反复用。
孔隙率 n = Vv / V 0% 孔隙体积占总体积的比例。注意 n 和 e 不是一回事。
饱和度 Sr = Vw / Vv 0% 水占孔隙的比例。Va 变成 0 时，Sr 才是 100%。
含水率 w = mw / ms 0% 质量比，不是体积比。考试最容易把 w 和 Sr 混。
干重度 gamma_d 0 只看土粒质量除以总体积，可由 Gs、e 推出来。
天然重度 gamma 0 土粒和水一起算重量，气体重量通常忽略。
做题顺序：先画三相图，填已知量；再找目标量属于“体积比、质量比还是重度”；最后用 e、n、Sr、w、Gs 之间的桥接关系换算。不要上来背一堆公式。

暂停检查点

  1. 只增加 Vw，不改变 Vs 和 Va：w、Sr、e、n 分别怎么变？
  2. 只减少 Va，让水填满孔隙：哪个指标会接近 100%？哪个指标不一定变？
  3. 只压密土体，让 Vv 变小：e 和 gamma_d 会怎样？为什么？
  4. 闭眼默写：e、n、Sr、w 四个指标的分子分母分别是什么。
