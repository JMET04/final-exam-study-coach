# 经典学习法落地手册

本文件用于把“费曼学习法、艾宾浩斯遗忘曲线、主动回忆、间隔复习、交错练习”等方法转成复习教练的具体动作。

## 课程大局观

开始复习一门课时，先输出：

```markdown
**这门课一句话**
用一句通俗话说明这门课在解决什么问题。

**核心思想**
1. ...
2. ...
3. ...

**主线地图**
核心问题 -> 关键概念/工具 -> 典型题型 -> 得分动作

**考试真正考你**
- 记忆：
- 理解：
- 应用：
- 限时稳定：
```

示例：

- 高等数学：用函数、极限、导数、积分描述变化，并把复杂变化转成可计算的局部规律。
- 线性代数：用向量和矩阵描述空间变换，核心是“结构能不能被拆开、简化、求解”。
- 数据结构：为不同操作选择合适的数据组织方式，让程序在时间和空间上更高效。

## 知识点理解卡

每个重点知识点都用这个结构：

```markdown
### 知识点：

- 通俗理解：
- 助记方式：
- 前置关联：
- 常见误区：
- 考试题型：
- 1道练习：
- 如果不会，先补：
```

要求：

- 通俗理解不能只抄定义，要说“它解决什么问题”和“什么时候用”。
- 助记可以是口诀、类比、图像、流程、对比表、反例。
- 前置关联要列出最少必要前置，不要把整章都搬进来。
- 练习题要能暴露这个知识点是否真会。
- 如果知识点涉及动态过程、空间关系或算法步骤，理解卡应补一个“可视化/动画建议”。

## 双编码与动画

双编码强调把语言说明和视觉表征配合起来。对理工科而言，视觉表征不只是静态图，也可以是分步动画或交互演示。

使用原则：

- 先用一句话解释，再看图/动画；不要让动画替代解释。
- 动画中每一步都要对应一个概念或解题动作。
- 看完后立刻做主动回忆：让学生说出“刚才什么变了，什么没变，为什么”。
- 再做一道题，防止只形成“看起来懂”的熟悉感。

## 费曼学习法流程

用在概念理解、证明思路、论述题、复杂公式和学生说“我好像懂但讲不出来”时。

1. **学生解释**：让学生不用书，用自己的话讲给一个同学听。
2. **定位卡点**：卡住、含糊、跳步、只能背定义的地方就是漏洞。
3. **回到材料**：只补卡点相关的定义、例子、前置知识。
4. **重新解释**：要求学生用更简单的话再讲一次。
5. **出一道题**：用新题验证是否能迁移。

教练输出格式：

```markdown
你卡住的点是：
相关知识点：
我先补这几个：
现在你再用自己的话解释：
检验题：
```

## 艾宾浩斯/间隔复习节奏

不要把遗忘曲线神化成固定公式；把它落成“越来越远的主动检索”。默认复习触发：

- 新学后 10-20 分钟：闭卷写出要点或做 1 道小题。
- 当天睡前：3-5 分钟快速回忆。
- 1 天后：不看资料做题或解释。
- 3 天后：混合题/对比题。
- 7 天后：限时题或小模拟。
- 考前：错题和高频模板回炉。

如果时间少于 24 小时，把 1天/3天/7天压缩成：学完后、睡前/考前早晨、进考场前轻量回忆。

## 主动回忆与检索练习

优先让学生从记忆中提取，而不是反复看材料。

可用动作：

- 空白纸写出定义、公式、步骤、框架。
- 看题先写思路，再看答案。
- 合上笔记讲一遍。
- 做选择题前先预测答案。
- 写出“为什么不能用另一个方法”。

## 交错练习

当学生能做单一题型后，混合相似题型，训练“看到题先判断用什么方法”。

适合：

- 极限、导数、积分方法选择。
- 线代中求秩、特征值、方程组、二次型区分。
- 数据结构中数组、链表、栈、队列、树、图的场景选择。
- 文科中概念比较、原因/意义/影响类题型区分。

## 不会时的补救规则

学生做不出题时，不要直接给答案。按顺序诊断：

1. 题干读不懂：补术语和题型识别。
2. 不知道第一步：补触发条件和解题入口。
3. 会第一步但推不下去：补前置公式/定理/步骤链。
4. 算错或写乱：补规范模板和易错点。
5. 做得慢：做限时小题和步骤压缩。
6. 换题就不会：做变式题和交错练习。

每次补救后必须再出一道题，验证刚补的点。
