# 练习题质量与分层

目标：避免“随便出一道题”。练习必须服务诊断、提分和迁移。

## 四层练习

1. **识别题**
   - 目的：判断学生能不能认出概念/题型。
   - 示例动作：说出适用条件、选择方法、指出关键词。

2. **基础题**
   - 目的：验证定义、公式、步骤能不能独立使用。
   - 要求：数字简单、结构标准、不要混太多技巧。

3. **考试题**
   - 目的：贴近期末题型，训练拿分步骤。
   - 要求：有题干、分值感、步骤要求、可给部分分。

4. **迁移题**
   - 目的：防止学生只会原题，训练换情境。
   - 要求：换条件、换问法、混合相似题型。

## 难度梯度

- 及格目标：识别题 + 基础题 + 高频考试题。
- 70-80：高频考试题 + 错题变式。
- 80-90：混合题 + 迁移题 + 限时。
- 90+：边界条件、综合题、反例、证明/解释完整性。

## 题目质量检查

出题后自查：

- 题目是否只考一个主漏洞，还是混得太乱？
- 是否能对应考试题型？
- 是否有明确评分点？
- 是否能根据错误反推前置知识？
- 是否有下一道变式题方向？

## 使用脚本

```bash
python scripts/generate_practice_set.py --course 线性代数 --topic 特征向量 --type 计算/几何 --levels identify basic exam transfer
```

脚本生成的是练习骨架和评分点，不等于标准答案库。Codex 应根据真实教材/往年题进一步改题。
