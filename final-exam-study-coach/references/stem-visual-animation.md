# 理工科演示动画与可视化

理工科很多知识不是“背一句定义”就能懂，而是要看到变化过程、结构关系、步骤演化。动画和交互可视化可以帮助学生建立动态模型，但只在能减少误解或提高做题能力时使用。

## 什么时候值得做动画

优先用于：

- **变化过程**：极限逼近、导数切线变化、积分累积、微分方程轨迹。
- **空间关系**：向量投影、矩阵变换、特征向量、三维几何、力的分解。
- **算法步骤**：排序、搜索、递归、图遍历、动态规划状态转移。
- **系统演化**：电路暂态、控制反馈、热传导、流体、振动、概率转移。
- **结构操作**：链表插入删除、栈队列、树旋转、堆调整、哈希冲突。
- **微观过程**：化学反应路径、细胞过程、信号传导、材料结构变化。

不建议为了好看而做动画。以下情况用静态图或例题更好：

- 纯记忆清单。
- 简单定义。
- 公式代入型题目，动画不会改变理解。
- 时间极短且学生更需要题型模板。
- 文科、思政、历史、管理学概念课等没有具象动态原理时，使用主线图、时间线、概念对比表、论述模板、主动回忆和短测，不要强行动画化。

## 动画输出模板

```markdown
**动画目标**
学生看完要理解什么动态关系？

**演示对象**
变量、图形、状态、节点、力、电流、概率等。

**关键帧**
1. 初始状态：
2. 变化/操作：
3. 关键转折：
4. 结果状态：

**暂停提问**
- 这里什么量没有变？
- 哪个量在增加/减少？
- 如果条件改变，下一帧会怎样？

**接一道题**
...
```

## 形式选择

- **Mermaid**：流程、状态机、算法步骤、知识关系图。
- **SVG**：简单几何、向量、力图、数据结构节点关系。
- **HTML Canvas**：函数图像变化、算法动画、粒子/概率流动。
- **Matplotlib**：数学图像、曲线族、统计分布、工程图。
- **Manim**：高质量数学动画，适合导数、积分、线代、概率推导。
- **Three.js**：三维空间、刚体、立体几何、场景交互；只有确实需要 3D 时使用。

如果用户只是要复习计划，不一定实际生成文件；可以先给“建议做什么动画”。如果用户要“做出来”，再生成相应 HTML/SVG/脚本文件。

## 学科建议

### 高等数学

- 极限：点沿曲线逼近、左右极限对比。
- 导数：割线逐渐变切线，斜率变化。
- 积分：小矩形累积成面积。
- 多元函数：等高线和梯度方向。

### 线性代数

- 矩阵变换：网格被拉伸、旋转、剪切。
- 特征向量：变换后方向不变，只伸缩。
- 行列式：单位面积/体积被缩放的倍数。
- 线性方程组：行变换如何保持解集。

### 概率统计

- 条件概率/贝叶斯：样本空间被筛选，概率质量重新分配。
- 分布：直方图到密度曲线。
- 大数定律：样本均值逐渐稳定。
- 中心极限定理：多次抽样均值分布趋近钟形。

### 物理/工程

- 力学：受力分解、速度/加速度矢量变化。
- 电路：电流路径、电容充放电、电压变化。
- 控制：反馈环路、误差收敛、振荡。
- 热/流体：梯度驱动的传递过程。

### 编程/数据结构

- 排序：元素比较和交换。
- 图遍历：访问队列/栈、已访问集合、边的探索。
- 动态规划：状态表如何被填充。
- 递归：调用栈展开和回收。

## 动画后的学习动作

动画看完必须跟练习，否则容易形成“看懂错觉”：

1. 让学生闭眼复述刚才的变化过程。
2. 让学生预测下一帧。
3. 改一个条件，让学生判断结果如何变。
4. 出一道题验证能不能迁移。
5. 如果不会，回到相关前置知识点，而不是重复播放动画。
6. 安排定时复习检测：10 分钟后默画/复述，当天结束小测，第二天开始复测，3-7 天做混合题回炉。

## 生成文件时的质量要求

- 动画第一屏就能看出主题，不要只有装饰。
- 每个阶段有明确标签或暂停点。
- 控件简单：播放/暂停/重置/速度即可。
- 移动端和桌面都能看清关键文字。
- 不用复杂依赖时，优先单文件 HTML + Canvas/SVG。
- 如果做 3D，要验证画面非空、对象入镜、交互可用。

python scripts/generate_animation_demo.py eigenvector --output eigenvector.html

python scripts/generate_animation_demo.py derivative --output derivative.html

这些模板是单文件 HTML，适合期末快速演示。生成后要配合提问和练习，不要只让学生观看。
