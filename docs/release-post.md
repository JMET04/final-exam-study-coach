# 发布文案

## 中文长文版

我做了一个新的 Codex skill：**Final Exam Study Coach / 期末复习教练**。

它是给大学生期末周用的，不只是生成复习计划，而是更像给自己请了个一对一家教老师：

- 零碎时间不知道该看啥，它会拆出下一学习块。
- 知识点原理太复杂，文字看不懂，它能生成原理动画互动网页。
- 知识太多抓不住重点，它会按提分收益排序。
- 背诵没人检查，它会用主动回忆和短测盯住。
- 知识点没人答疑，它会在对话里解释、纠错、继续推进。

我最喜欢的是图里展示的原理动画功能：  
对土力学、工程、数学、物理这类有具象原理的课程，只需要较少 token，就能快速生成对应的互动网页。学生可以拖动参数、观察变量变化，先把基本原理看懂，再去背公式和做题。

学习机制也不是乱来的：它参考费曼学习法和艾宾浩斯遗忘曲线。先让学生用自己的话讲出来，再用短测、间隔复习、错题归因和下一轮复测持续检查。整个过程比“看一遍资料”科学很多。

使用方法很简单：把任何能包含全部知识点的资料喂给 AI 就可以，包括但不限于 PDF 版课本、老师的 PPT、课堂笔记、考试范围、往年题。

总之，它解决的是期末复习最真实的几个问题：不知道看啥、看不懂原理、抓不住重点、没人检查背诵、没人答疑。  
大学生终于也能拥有自己的复习家教老师了。

发布包里还放了真实产出展示素材：

- 土力学基本原理动画截图。
- 毛思互动带学真实摘录展示。
- 毛思清晰思维导图。

我也补了一份 token 成本报告，尤其说明了土力学动画相关生成的 goal 级用量和估算方式。

## 社交媒体短版

做了一个 Codex skill：期末复习教练。

它会根据 PDF 课本、老师 PPT、笔记、考试范围、往年题和剩余时间，自动生成提分计划，并像一对一家教老师一样带你复习。

亮点：
- 零碎时间直接告诉你该看啥
- 原理太复杂就生成互动动画网页
- 知识太多就按提分收益抓重点
- 背诵用主动回忆和短测检查
- 机制参考费曼学习法 + 艾宾浩斯遗忘曲线
- 把资料喂给 AI，就开始一对一带学

不是让 AI 给你画一张漂亮计划表，而是让它真正带你学到能考试。

## GitHub Release 摘要

v0.1.0 发布：Final Exam Study Coach 初版。

这是一个面向大学期末复习的 Codex skill，支持材料整理、课程建模、提分计划、拖延缓冲、带学复盘、定时检测、上下文恢复，以及理工科具象原理动画判断。
