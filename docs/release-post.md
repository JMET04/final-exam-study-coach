# 发布文案

## 中文长文版

我做了一个新的 Codex skill：**Final Exam Study Coach / 期末复习教练**。

它是给大学生期末周用的，不只是生成复习计划，而是像私人学习秘书一样工作：

- 读取教材、课件、笔记、考试范围、往年题。
- 先判断这门课到底考什么能力。
- 按提分收益排序，而不是照章节硬排。
- 默认考虑拖延，把核心任务排进 70-80% 可用时间。
- 如果学生没完成，会立即重排计划。
- 带着学生讲解、回忆、短测、做题、错题复盘。
- 跨天或上下文压缩后，用检查点恢复进度。

这次我还加了一个很重要的判断：  
**只有理工科这类有具象动态原理的课程，才先做动画或交互可视化。**

比如土力学，可以先看三相组成、有效应力、达西渗流、莫尔-库伦强度这些基本原理动画，先建立知识骨架；但思政、历史这类课不会硬做动画，而是继续用主线图、时间线、对比表、主动回忆和论述题模板。

核心目标很简单：  
让学生从“资料很多但不知道怎么学”，变成“现在就知道下一步做什么，并且能一步步把分提上来”。

发布包里还放了展示素材：

- 土力学基本原理动画展示。
- 毛思互动带学脱敏展示。
- 毛思清晰思维导图。

我也补了一份 token 成本报告，尤其说明了土力学动画相关生成的 goal 级用量和估算方式。

## 社交媒体短版

做了一个 Codex skill：期末复习教练。

它会根据教材、PPT、笔记、考试范围、往年题和剩余时间，自动生成提分计划，并像私人学习秘书一样带你复习。

亮点：
- 按提分收益排优先级
- 默认考虑拖延，计划自带缓冲
- 没完成会自动重排
- 理工科先用具象原理动画建知识骨架
- 文科用主线图、时间线、对比表和主动回忆
- 跨天学习不丢进度
- 附带展示栏和 token 成本报告

不是让 AI 给你画一张漂亮计划表，而是让它真正带你学到能考试。
