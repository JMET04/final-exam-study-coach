# Release Notes v0.1.0

## Highlights

- Added the complete `final-exam-study-coach` skill package.
- Added a private-secretary style workflow for final-exam preparation.
- Added material intake, course modeling, score-improvement planning, and study-session coaching.
- Added procrastination-aware scheduling: core work is planned into 70-80% of available time.
- Added context-continuity rules for long-running and cross-day study plans.
- Added concrete-principle animation onboarding for STEM-like subjects.
- Added clear boundaries for humanities subjects: use timelines, concept maps, comparison tables, retrieval practice, and short tests instead of forced animations.
- Added scheduled review checks after each learning block.

## Included Example

The repository includes generated soil mechanics demo animations:

- Three-phase soil composition and index conversion.
- Effective stress principle.
- Darcy seepage.
- Mohr-Coulomb shear strength.

These examples demonstrate how the skill can use concrete animated principles before moving into exam practice.
