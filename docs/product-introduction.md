# 产品介绍 · v0.5.0

期末复习与大学带学将课程材料、学习证据和当前疑问组织成可接续的教学路径，适用于平时跟课、期末与补考复习。当前安装方式与示例以 [README](../README.md) 为准。

教师先分析完整单元或题目：用途与原理、条件分支、每步输入输出、参数查表、完整验收和失败回退；对话再逐段讲解当前问题。新术语和符号解释含义、位置、单位，位置量配图。课件优先与本书模式由用户选择，不混用版本和规范。

对话先讲因果，再按需展示一个极简动画段。画面只有图形、必要短标注和手动控件；讲解词、推导和提问在对话或独立数据中。历史截图和 `examples/legacy-animation-templates.py` 展示旧版本能力，不能作为当前显示契约或新浏览器验收的证据。

学习状态区分备课、核读、已展示、待学、局部理解与独立掌握。学生未学的最新输出仍待学，迁移不推进掌握或复测；暂停不会被答疑、发布和启用书灵自动解除。状态脚本只在新的独立作答时更新掌握与复测；自述理解、教师反馈和未完成任务只记录相应事件。

书灵是独立可选项，按书名、版本和覆盖范围取预建知识、条件、动画与讲解词。公共书包采用开放文件格式，可由任意AI读取；基础插件不依赖它。书库支持Fork与PR投稿，语义、来源、动画和格式检查分别登记。

[旧版发布记录](release-notes-v0.1.0.md) 与 [历史成本记录](token-cost-report.md) 仅描述当时范围，不代表当前发布核验或全书完成。
